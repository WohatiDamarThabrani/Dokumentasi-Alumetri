# Dokumentasi Proyek

Dokumentasi proyek ini dibuat dengan VitePress.

## Persiapan

```bash
npm install
```

## Jalankan di lokal

```bash
npm run docs:dev
```

## Build untuk produksi

```bash
npm run docs:build
```

## Struktur proyek

- `docs/` : berisi halaman dokumentasi markdown
- `.vitepress/` : konfigurasi VitePress
- `package.json` : konfigurasi proyek dan script

## Catatan

Project ini siap untuk di-push ke GitHub dan dikembangkan lebih lanjut.
