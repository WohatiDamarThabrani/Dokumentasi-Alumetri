# Estimator

Estimator menyusun quotation berdasarkan informasi proyek, tipe rumah, pengaturan komersial, kode gambar, dan komponen yang digunakan.

## Halaman Estimator

- [Dashboard](/roles/estimator/dashboard) — ringkasan proyek aktif, penawaran menunggu, progress berjalan, dan daftar proyek aktif.
- [Import Project](/roles/estimator/import-project) — mengunggah shop drawing ke dalam sistem.
- [Daftar Produksi](/roles/estimator/daftar-produksi) — memantau progres produksi project, rincian komponen, dan riwayat pencatatan produksi.
- [Menahan dan Membatalkan Project](/roles/estimator/daftar-project) — membuka detail proyek untuk menahan atau membatalkan proyek.
- [Daftar Quotation](/roles/estimator/daftar-quotation) — daftar quotation dan panduan membuat draft untuk ditinjau admin.
