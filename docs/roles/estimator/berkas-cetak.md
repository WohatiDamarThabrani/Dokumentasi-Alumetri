# Berkas Cetak

Halaman **Berkas Cetak** pada modul **Cetak** digunakan Estimator untuk memilih dokumen yang akan diunduh atau dicetak.

## Cara Mengunduh dan Mencetak Dokumen

1. Buka menu Berkas Cetak
   <img src="/images/purchasing/cetak/cetak1.png" alt="" style="display: block; max-width: 100%; height: auto;">

2. Klik dokumen yang diperlukan, lalu akan tampil halaman seperti berikut
   <img src="/images/purchasing/cetak/cetak2.png" alt="" style="display: block; max-width: 100%; height: auto;">

3. Klik tombol <img src="/images/purchasing/cetak/cetak3.png" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle;  margin: 0;"> untuk mengunduh dokumen
   
4. Klik tombol <img src="/images/purchasing/cetak/cetak4.png" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> untuk mencetak dokumen
