# Menahan dan Membatalkan Project

Estimator dapat menahan project untuk mengubah statusnya menjadi **On Hold**, atau membatalkan project melalui halaman Daftar Project.

## Langkah Menahan atau Membatalkan Project

1. Buka halaman **Daftar Project**.
2. Klik project yang ingin ditahan atau dibatalkan untuk membuka detail project.
3. Untuk menahan project, klik tombol **Tahan**. Status project akan berubah menjadi **On Hold**.
4. Untuk membatalkan project, klik tombol **Batalkan**.
