# Import Project

Estimator dapat mengimpor project dengan mengunggah shop drawing ke dalam sistem, seperti Purchasing.

## Mengunggah Shop Drawing

1. Buka halaman **Import Project**.
2. Pilih atau unggah file shop drawing yang akan dimasukkan ke sistem.
3. Periksa file yang dipilih, lalu jalankan proses import sesuai tindakan yang tersedia pada halaman.
4. Pastikan proses import selesai sebelum melanjutkan pekerjaan pada project.

Shop drawing yang berhasil diimpor menjadi acuan informasi project di dalam sistem.
