# Parameter Teknis

Halaman **Parameter Teknis** pada modul **Master Data** digunakan Estimator untuk mengelola konstanta bernama yang dapat dipakai pada baris rumus. Estimator dapat menambah, mengubah, mengimpor, mengekspor, menghapus, dan memulihkan parameter. Parameter berlaku pada setiap rumus yang menyebutkannya, selama brand dan tipe unit rumus tersebut sesuai dengan lingkup parameter.

## Menambahkan Parameter Teknis

1. Buka halaman **Parameter Teknis** dari modul **Master Data**.
2. Klik **Tambah Parameter** di bagian atas halaman.
3. Isi data parameter berikut:

| Informasi | Keterangan |
| --- | --- |
| **Kode** | Nama/kode konstanta yang disebutkan pada rumus. |
| **Nama** | Nama yang menjelaskan parameter. |
| **Jenis Isi** | **Nilai Tetap** jika parameter berisi nilai langsung, atau **Rumus** jika parameter dihitung dari rumus. |
| **Rumus** | Isi dengan nilai tetap atau ekspresi rumus sesuai **Jenis Isi** yang dipilih. |
| **Satuan** | Satuan untuk nilai parameter. |
| **Lingkup Brand** | Brand yang menggunakan parameter, atau **Global** untuk lintas brand. |
| **Lingkup Tipe Unit** | Tipe unit yang menggunakan parameter, atau **Semua Tipe Unit**. |
| **Catatan** | Keterangan tambahan; opsional. |

4. Simpan parameter. Pastikan kode yang digunakan pada baris rumus sesuai dengan **Kode** parameter.

## Mengelola Parameter Teknis

Gunakan tindakan pada tabel untuk mengubah atau menghapus parameter. Parameter yang dihapus masuk ke **Kotak Sampah** dan dapat dipulihkan atau dihapus permanen. Fitur impor dan ekspor tersedia seperti pada halaman master data lainnya.
