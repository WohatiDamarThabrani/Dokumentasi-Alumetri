# Project & Production

Modul **Project & Production** pada role Estimator digunakan untuk mengimpor project, mengelola status project, dan memantau progres produksi.

## Halaman Project & Production

- [Import Project](/roles/estimator/import-project) — mengunggah shop drawing ke dalam sistem.
- [Daftar Project](/roles/estimator/daftar-project) — melihat ringkasan project, membuka detail, serta menahan atau membatalkan project.
- [Menahan dan Membatalkan Project](/roles/estimator/tahan-batalkan-project) — langkah khusus untuk mengubah status project.
- [Daftar Produksi](/roles/estimator/daftar-produksi) — memantau progres produksi project, rincian komponen, dan riwayat pencatatan produksi.
