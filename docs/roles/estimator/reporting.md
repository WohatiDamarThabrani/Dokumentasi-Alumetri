# Report

Modul **Report** pada Estimator merangkum hasil penawaran dan pelaksanaan project untuk membantu memantau performa komersial serta kebutuhan operasional.

## Halaman Report

- [Report](/roles/estimator/report) — merangkum status dan nilai penawaran, performa project, progress produksi, kebutuhan material, sisa potong dan scrap, pengiriman, serta COGS internal.
