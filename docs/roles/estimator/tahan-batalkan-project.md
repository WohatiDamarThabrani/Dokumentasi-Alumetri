# Menahan dan Membatalkan Project

Estimator dapat menahan project untuk mengubah statusnya menjadi **On Hold**, atau membatalkan project melalui halaman Daftar Project.

## Cara Menahan Project

1. Buka menu Daftar Project.
   <img src="/images/estimator/tahan-batal-proyek/tahan1.png" alt="" style="display: block; max-width: 100%; height: auto;">

2. Klik proyek yang ingin ditahan. Selanjutnya akan tampil halaman berikut
   <img src="/images/estimator/tahan-batal-proyek/tahan2.png" alt="" style="display: block; max-width: 100%; height: auto;">

3. Klik tombol <img src="/images/estimator/tahan-batal-proyek/tahan3.png" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;">

4. Lalu akan muncul pop up seperti ini <img src="/images/estimator/tahan-batal-proyek/tahan4.png" alt="" style="display: block; max-width: 100%; height: auto;">

5. Klik tombol <img src="/images/estimator/tahan-batal-proyek/tahan5.png" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> untuk menahan proyek


## Cara Membatalkan Project

1. Buka menu Daftar Project.
   <img src="/images/estimator/tahan-batal-proyek/tahan1.png" alt="" style="display: block; max-width: 100%; height: auto;">

2. Klik proyek yang ingin dibatalkan. Selanjutnya akan tampil halaman berikut
   <img src="/images/estimator/tahan-batal-proyek/tahan2.png" alt="" style="display: block; max-width: 100%; height: auto;">

3. Klik tombol <img src="/images/estimator/tahan-batal-proyek/tahan6.png" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;">

4. Lalu akan muncul pop up seperti ini <img src="/images/estimator/tahan-batal-proyek/tahan7.png" alt="" style="display: block; max-width: 100%; height: auto;">

5. Klik tombol <img src="/images/estimator/tahan-batal-proyek/tahan8.png" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> untuk membatalkan proyek
