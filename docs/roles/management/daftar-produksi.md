# Daftar Produksi

Halaman **Daftar Produksi** membantu Management memantau progress produksi proyek yang sedang berjalan, mulai dari ringkasan hingga rincian per komponen dan riwayat pencatatan produksi. Seluruh informasi pada halaman ini bersifat baca-saja untuk Management.

## Memilih Proyek

Pilih proyek yang sedang berjalan untuk melihat data produksinya. Informasi yang ditampilkan mengikuti proyek yang dipilih.

## Ringkasan Produksi

| Informasi | Keterangan |
| --- | --- |
| **Total rencana produksi** | Jumlah seluruh komponen yang direncanakan untuk diproduksi. |
| **Total selesai produksi** | Jumlah komponen yang sudah selesai diproduksi. |
| **Total siap kirim** | Jumlah komponen yang siap dikirim. |
| **Total belum diproduksi** | Jumlah komponen yang belum diproduksi. |

## Tabel Komponen

| Kolom | Keterangan |
| --- | --- |
| **Kode gambar** | Kode gambar teknis komponen. |
| **Nama komponen** | Nama komponen. |
| **Dimensi** | Ukuran komponen. |
| **Total diproduksi** | Jumlah komponen yang direncanakan untuk diproduksi. |
| **Selesai diproduksi** | Jumlah komponen yang sudah selesai diproduksi. |
| **Sisa belum diproduksi** | Jumlah komponen yang belum diproduksi. |
| **Progres (%)** | Persentase progres produksi komponen. |
| **Status terkirim** | Status pengiriman komponen. |
| **Stok** | Jumlah komponen yang tersedia saat ini. |

## Tabel Catatan Produksi

Tabel ini berisi riwayat pencatatan produksi untuk proyek yang dipilih.

| Kolom | Keterangan |
| --- | --- |
| **Tanggal** | Tanggal produksi dicatat. |
| **Proyek** | Proyek terkait. |
| **Batch** | Batch terkait. |
| **Baris** | Baris komponen yang terkait dengan pencatatan produksi. |
| **Quantity** | Jumlah komponen yang diproduksi. |
| **Pencatat** | Pengguna yang mencatat produksi. |
