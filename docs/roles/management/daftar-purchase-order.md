# Daftar Purchase Order

Halaman ini digunakan Management untuk membaca informasi Purchase Order (PO) yang tercatat untuk proyek. Management dapat meninjau rincian pemesanan dan statusnya, tetapi tidak dapat membuat, mengubah, atau mengajukan PO.

## Informasi Purchase Order

Informasi PO mencakup pemasok, kategori material, serta material yang dipesan. Rincian material dapat meliputi:

| Informasi | Keterangan |
| --- | --- |
| **Kode section profil** | Kode section untuk material profil. |
| **Length** | Panjang material. |
| **Finish color** | Warna finishing material. |
| **Quantity** | Jumlah material yang dipesan. |
| **Unit price** | Harga satuan material. |
| **Amount** | Nilai untuk material tersebut. |
| **Total harga** | Total nilai PO. |

PO yang diajukan untuk ditinjau dikirim ke role Super Admin untuk disetujui. Management dapat membaca informasi PO dan statusnya tanpa melakukan tindakan terhadap PO.
