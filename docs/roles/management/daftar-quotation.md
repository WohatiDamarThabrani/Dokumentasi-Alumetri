# Daftar Quotation

Halaman ini menampilkan daftar quotation untuk dibaca dan ditinjau oleh Management. Role Management tidak dapat membuat atau mengubah quotation.

| Kolom | Keterangan |
| --- | --- |
| **No Quotation** | Nomor identifikasi quotation. |
| **Brand** | Brand yang digunakan pada proyek. |
| **Nama Proyek** | Nama proyek terkait quotation. |
| **Cluster** | Cluster proyek. |
| **Type** | Tipe rumah pada quotation. |
| **Qty Rumah** | Jumlah rumah yang dihitung. |
| **Nilai Project** | Nilai proyek pada quotation. |
| **Status** | Status quotation saat ini. |
| **Last Update** | Waktu terakhir quotation diperbarui. |

Gunakan informasi pada tabel untuk meninjau data dan status quotation. Fitur aksi untuk membuat draft atau mengubah quotation tidak tersedia bagi Management.
