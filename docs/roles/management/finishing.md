# Finishing

Halaman **Finishing** pada modul **Master Data** menampilkan data warna dan lapisan permukaan yang digunakan pada profil.

## Melihat Data Finishing

Tinjau kode dan nama finishing pada tabel. Data ini menjelaskan warna atau lapisan permukaan profil.

## Mengekspor Data Finishing

Klik **Export** untuk mengunduh daftar finishing dalam format Excel.

Management hanya dapat melihat dan mengekspor data. Fitur untuk menambah, mengubah, mengimpor, atau menghapus finishing tidak tersedia.
