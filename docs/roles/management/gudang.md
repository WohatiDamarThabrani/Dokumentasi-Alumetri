# Gudang

Halaman **Gudang** pada modul **Master Data** menampilkan data gudang fisik tempat stok disimpan.

## Melihat Data Gudang

Tinjau kode dan nama gudang, status sebagai gudang bawaan, status aktif, serta alamat jika tersedia.

## Mengekspor Data Gudang

Klik **Export** untuk mengunduh daftar gudang dalam format Excel.

Management hanya dapat melihat dan mengekspor data. Fitur untuk menambah, mengubah, mengimpor, atau menghapus gudang tidak tersedia.
