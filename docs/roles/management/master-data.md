# Master Data

Modul **Master Data** pada role Management menyediakan data referensi untuk ditinjau dan diekspor. Management hanya dapat membaca dan mengekspor data pada halaman-halaman ini; fitur untuk menambah, mengubah, atau menghapus data tidak tersedia.

## Halaman Master Data

- [Brand](/roles/management/brand) — melihat daftar brand.
- [Seri Profil](/roles/management/seri-profil) — melihat seri profil berdasarkan brand.
- [Finishing](/roles/management/finishing) — melihat warna dan lapisan permukaan profil.
- [Supplier](/roles/management/supplier) — melihat data pemasok aluminium, aksesoris, dan kaca.
- [Customer](/roles/management/customer) — melihat data customer.
- [Gudang](/roles/management/gudang) — melihat data gudang penyimpanan.
- [Unit Type & BOM](/roles/management/unit-type-bom) — melihat tipe unit dan bill of materials.
- [Parameter Teknis](/roles/management/parameter-teknis) — melihat konstanta yang digunakan dalam rumus teknis.
- [Profil Aluminium](/roles/management/profil-aluminium) — melihat spesifikasi profil aluminium.
- [Aksesoris](/roles/management/aksesoris) — melihat data aksesoris.
- [Glass](/roles/management/glass) — melihat data jenis kaca.
- [Jasa Pemasangan](/roles/management/jasa-pemasangan) — melihat katalog jasa pemasangan.
- [Price & Cost](/roles/management/price-cost) — melihat daftar harga dan biaya.

Pada setiap halaman, gunakan aksi **Ekspor** untuk mengunduh data yang sedang ditampilkan.
