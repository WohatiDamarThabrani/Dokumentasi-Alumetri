# Parameter Teknis

Halaman **Parameter Teknis** pada modul **Master Data** menampilkan konstanta bernama yang digunakan pada baris rumus. Parameter berlaku pada rumus yang menyebutkannya selama brand dan tipe unit rumus sesuai dengan lingkup parameter.

## Melihat Data Parameter Teknis

Tinjau kolom-kolom berikut pada daftar parameter:

| Informasi | Keterangan |
| --- | --- |
| **Kode** | Nama/kode konstanta yang disebutkan pada rumus. |
| **Nama** | Nama yang menjelaskan parameter. |
| **Jenis Isi** | Menunjukkan apakah parameter menggunakan nilai tetap atau rumus. |
| **Rumus** | Nilai tetap atau ekspresi rumus yang disimpan. |
| **Satuan** | Satuan untuk nilai parameter. |
| **Lingkup Brand** | Brand yang menggunakan parameter atau **Global** untuk lintas brand. |
| **Lingkup Tipe Unit** | Tipe unit yang menggunakan parameter atau **Semua Tipe Unit**. |
| **Catatan** | Keterangan tambahan jika tersedia. |

## Mengekspor Parameter Teknis

Gunakan aksi **Export** untuk mengunduh data parameter teknis dalam format yang disediakan halaman.

Management hanya dapat melihat dan mengekspor data. Fitur untuk menambah, mengubah, mengimpor, atau menghapus parameter tidak tersedia.
