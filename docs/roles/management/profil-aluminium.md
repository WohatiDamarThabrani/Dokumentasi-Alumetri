# Profil Aluminium

Halaman **Profil Aluminium** pada modul **Master Data** menampilkan spesifikasi profil aluminium yang digunakan dalam sistem.

## Melihat Data Profil Aluminium

Tinjau kode profil, deskripsi, deskripsi lapangan, berat per meter, brand, seri, panjang batang, dan finishing pada daftar profil. Harga terendah tanpa PPN dikelola melalui data **Price & Cost**.

## Mengekspor Data Profil Aluminium

Klik **Export** untuk mengunduh daftar profil aluminium dalam format Excel.

Management hanya dapat melihat dan mengekspor data. Fitur untuk menambah, mengubah, mengimpor, atau menghapus profil tidak tersedia.
