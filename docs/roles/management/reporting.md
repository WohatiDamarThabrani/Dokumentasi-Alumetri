# Report

Modul **Report** pada Management menyediakan ringkasan untuk meninjau penawaran dan pelaksanaan project. Informasi pada report digunakan untuk memantau performa komersial dan operasional.

## Halaman Report

- [Report](/roles/management/report) — meninjau status dan nilai penawaran, performa project, progress produksi, kebutuhan material, sisa potong dan scrap, pengiriman, serta COGS internal.
