# Seri Profil

Halaman **Seri Profil** pada modul **Master Data** menampilkan seri profil yang dikelompokkan berdasarkan brand.

## Melihat Data Seri Profil

Tinjau brand, kode seri, dan nama seri pada daftar. Seri profil menjadi referensi untuk mengelompokkan profil berdasarkan brand.

## Mengekspor Data Seri Profil

Gunakan aksi **Export** untuk mengunduh data seri profil dalam format yang disediakan halaman.

Management hanya dapat melihat dan mengekspor data. Fitur untuk menambah, mengubah, mengimpor, atau menghapus seri profil tidak tersedia.
