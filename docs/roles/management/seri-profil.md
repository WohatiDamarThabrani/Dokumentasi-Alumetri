# Seri Profil

Halaman **Seri Profil** pada modul **Master Data** menampilkan seri profil yang dikelompokkan berdasarkan brand.

## Cara Mengekspor Seri Profil

1. Buka menu seri profil.
   <img src="/images/super-admin/seri-profil/sf1.png" alt="" style="display: block; max-width: 100%; height: auto;">

2. Klik tombol <img src="/images/super-admin/seri-profil/sf16.png" alt="Buat Surat Jalan" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> untuk mengekspor seri profil

Management hanya dapat melihat dan mengekspor data. Fitur untuk menambah, mengubah, mengimpor, atau menghapus seri profil tidak tersedia.
