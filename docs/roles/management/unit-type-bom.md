# Unit Type & BOM

Halaman **Unit Type & BOM** pada modul **Master Data** menampilkan tipologi bukaan dan formula set yang menghitung Bill of Materials (BOM) setiap unit. Setiap tipologi memiliki formula set aktifnya masing-masing.

## Melihat Tipologi Unit

Tinjau informasi tipologi unit pada tabel:

| Informasi | Keterangan |
| --- | --- |
| **Kode Unit** | Kode untuk tipologi unit. |
| **Nama Unit** | Nama tipologi unit. |
| **Kategori** | Kategori unit. |
| **Brand** | Brand unit. |
| **Lebar Maksimal** | Batas lebar unit jika ditentukan. |
| **Tinggi Maksimal** | Batas tinggi unit jika ditentukan. |
| **Biaya Jasa** | Biaya jasa unit jika ditentukan. |

## Meninjau Formula Set BOM

Formula set BOM berisi baris komponen yang digunakan oleh tipologi unit. Informasi pada baris BOM mencakup grup komponen (**Aluminium**, **Aksesoris**, **Kaca**, atau **Jasa Pemasangan**), item/komponen, nomor part, UOM, tingkat pembulatan, serta rumus komponen seperti keterangan penggunaan, lebar potong, tinggi potong, dan jumlah.

Tinjau versi formula set dan status aktifnya pada tipologi terkait. Setiap tipologi menggunakan formula set aktifnya masing-masing.
