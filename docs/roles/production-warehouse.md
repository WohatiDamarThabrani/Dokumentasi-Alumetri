# Production + Warehouse

Role Production + Warehouse mencakup koordinasi proses produksi dan aktivitas gudang.

## Modul yang Dimiliki Production + Warehouse

- [Dashboard](/roles/production-warehouse/dashboard) — mencatat penerimaan dan transfer stok, memasukkan barang jadi, serta memantau progress proyek, produksi, pengiriman, dan aktivitas stok.
- [Project & Production](/roles/production-warehouse/project-production) — daftar produksi, inventory, dan surat jalan.
- [Cetak](/roles/production-warehouse/berkas-cetak) — memilih dokumen untuk diunduh atau dicetak.
