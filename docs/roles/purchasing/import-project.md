# Import Project

Halaman **Import Project** digunakan oleh Purchasing untuk mengunggah shop drawing ke dalam sistem.

## Mengunggah Shop Drawing

1. Buka halaman **Import Project**.
2. Pilih atau unggah file shop drawing yang akan dimasukkan ke sistem.
3. Periksa file yang dipilih, lalu jalankan proses import sesuai tindakan yang tersedia pada halaman.
4. Pastikan proses import selesai sebelum melanjutkan pekerjaan pada proyek.

Shop drawing yang berhasil diimpor menjadi acuan informasi proyek di dalam sistem.
