# Import Project

Halaman **Import Project** digunakan oleh Purchasing untuk mengunggah shop drawing ke dalam sistem.

## Cara Mengunggah Shop Drawing

1. Buka menu Import Proyek

   <img src="/images/purchasing/import_proyek/import1.png" alt="" style="display: block; max-width: 100%; height: auto;">

2. Pilih proyek dan tipe rumah dari dropdown list

3. Unggah file shop drawing. Setelah file diunggah, akan tampil halaman berikut

    <img src="/images/purchasing/import_proyek/import3.png" alt="" style="display: block; max-width: 100%; height: auto;">

4. Klik tombol <img src="/images/purchasing/import_proyek/import4.png" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle;">, lalu akan tampil halaman berikut

    <img src="/images/purchasing/import_proyek/import5.png" alt="" style="display: block; max-width: 100%; height: auto;">
   
5. Pilih kode gambar yang sesuai 

6. Klik tombol <img src="/images/purchasing/import_proyek/import6.png" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle;">, lalu akan tampil halaman berikut

    <img src="/images/purchasing/import_proyek/import7.png" alt="" style="display: block; max-width: 100%; height: auto;">

7. Klik tombol <img src="/images/purchasing/import_proyek/import8.png" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle;">, lalu akan tampil halaman berikut
