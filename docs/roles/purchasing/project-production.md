# Project & Production

Modul **Project & Production** pada role Purchasing mengelompokkan halaman untuk mengimpor project, membuat Purchase Order, memantau produksi, dan melihat persediaan barang.

## Halaman Project & Production

- [Import Project](/roles/purchasing/import-project) — mengunggah shop drawing ke dalam sistem.
- [Purchase Order](/roles/purchasing/purchase-order) — mencatat pemesanan material kepada pemasok untuk project.
- [Daftar Produksi](/roles/purchasing/daftar-produksi) — memantau progress dan riwayat produksi project.
- [Inventory Aluminium](/roles/purchasing/inventory-aluminium) — melihat stok profil aluminium.
- [Inventory Aksesoris](/roles/purchasing/inventory-aksesoris) — melihat stok aksesoris.
- [Inventory Glass](/roles/purchasing/inventory-glass) — melihat stok kaca.
- [Inventory Finished Good](/roles/purchasing/inventory-finished-good) — melihat barang jadi dan stok yang tersedia.
