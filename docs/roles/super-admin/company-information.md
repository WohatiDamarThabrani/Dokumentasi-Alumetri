# Company Information

Halaman **Company Information** digunakan Super Admin untuk mengelola identitas perusahaan yang tercetak pada penawaran, Purchase Order (PO), dan surat jalan.

Informasi perusahaan yang dapat diedit:

| Isian | Keterangan |
| --- | --- |
| **Nama Perusahaan** | Nama perusahaan. |
| **Alamat** | Alamat perusahaan. |
| **Telepon** | Nomor telepon perusahaan. |
| **Email** | Alamat email perusahaan. |
| **NPWP** | Nomor Pokok Wajib Pajak perusahaan. |
| **Website** | Alamat website perusahaan. |

Simpan perubahan agar identitas terbaru digunakan pada dokumen.

## Rekening

Informasi rekening perusahaan yang tercetak pada penawaran dan tagihan meliputi:

| Isian | Keterangan |
| --- | --- |
| **Bank** | Nama bank. |
| **No. Rekening** | Nomor rekening perusahaan. |
| **Atas Nama** | Nama pemilik rekening. |

Simpan perubahan agar informasi rekening terbaru digunakan pada dokumen.

## Logo Perusahaan

Unggah logo perusahaan melalui halaman ini dan simpan perubahan agar logo yang diperbarui dapat digunakan sebagai identitas pada dokumen.

## Penanda Tangan

Nama dan jabatan penanda tangan ditampilkan di kaki dokumen. Atur informasi berikut:

| Isian | Keterangan |
| --- | --- |
| **Nama** | Nama penanda tangan. |
| **Jabatan** | Jabatan penanda tangan. |

Simpan perubahan agar nama dan jabatan terbaru ditampilkan pada kaki dokumen.
