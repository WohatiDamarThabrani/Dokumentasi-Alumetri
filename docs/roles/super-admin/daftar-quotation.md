# Daftar Quotation

Halaman Daftar Quotation menampilkan quotation dalam bentuk tabel. Tugas Super Admin adalah meninjau dan menyetujui draft quotation yang diajukan oleh role lain.

| Kolom | Keterangan |
| --- | --- |
| **No Quotation** | Nomor identifikasi quotation. |
| **Brand** | Brand yang digunakan pada proyek. |
| **Nama Proyek** | Nama proyek terkait quotation. |
| **Cluster** | Cluster proyek. |
| **Type** | Tipe rumah pada quotation. |
| **Qty Rumah** | Jumlah rumah yang dihitung. |
| **Nilai Project** | Nilai proyek pada quotation. |
| **Status** | Status quotation saat ini. |
| **Last Update** | Waktu terakhir quotation diperbarui. |
| **Aksi** | Tindakan yang tersedia untuk quotation. |

Tinjau informasi proyek, tipe dan jumlah rumah, pengaturan komersial, kode gambar, serta komponen pada quotation. Setelah memastikan informasi draft yang diajukan role lain sudah sesuai, gunakan tindakan persetujuan yang tersedia.
