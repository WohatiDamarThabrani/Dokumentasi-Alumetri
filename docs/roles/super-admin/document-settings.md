# Document Settings

Halaman **Document Settings** digunakan Super Admin untuk mengatur template yang dicetak pada dokumen dan pola penomoran setiap dokumen.

## Mengatur Pola Penomoran

Super Admin dapat membuat atau mengedit pola penomoran untuk setiap jenis dokumen. Pilih dokumen yang akan diatur, lalu buat atau ubah pola penomorannya dan simpan perubahan.

## Mengatur Template Dokumen

Gunakan halaman ini untuk mengatur template yang akan tercetak pada dokumen. Periksa hasil pengaturan sebelum digunakan pada dokumen.
