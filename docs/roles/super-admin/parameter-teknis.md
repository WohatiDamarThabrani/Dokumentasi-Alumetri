# Parameter Teknis

Halaman **Parameter Teknis** pada modul **Master Data** digunakan untuk mengelola konstanta bernama yang dapat dipakai pada baris rumus. Parameter berlaku pada setiap rumus yang menyebutkannya, selama brand dan tipe unit rumus tersebut sesuai dengan lingkup parameter.

## Menambahkan Parameter Teknis

1. Buka halaman **Parameter Teknis** dari modul **Master Data**.
2. Klik **Tambah Parameter** di bagian atas halaman.
3. Isi data parameter berikut:

   | Isian | Keterangan |
   | --- | --- |
   | **Kode** | Nama/kode konstanta yang akan disebutkan pada rumus. Gunakan kode yang konsisten saat menulis rumus. |
   | **Nama** | Nama yang menjelaskan parameter. |
   | **Jenis Isi** | Pilih **Nilai Tetap** jika parameter berisi nilai langsung, atau **Rumus** jika parameter dihitung dari rumus. |
   | **Rumus** | Isi dengan nilai tetap atau ekspresi rumus, sesuai **Jenis Isi** yang dipilih. |
   | **Satuan** | Satuan untuk nilai parameter. |
   | **Lingkup Brand** | Pilih brand yang menggunakan parameter, atau pilih **Global** agar dapat digunakan lintas brand. |
   | **Lingkup Tipe Unit** | Pilih tipe unit yang menggunakan parameter, atau pilih **Semua Tipe Unit** agar dapat digunakan oleh semua tipe unit. |
   | **Catatan** | Keterangan tambahan; opsional. |

4. Simpan parameter. Pastikan kode yang digunakan pada baris rumus sesuai dengan **Kode** parameter.

## Mengelola Parameter Teknis

Gunakan tindakan pada tabel untuk mengubah atau menghapus parameter. Parameter yang dihapus masuk ke **Kotak Sampah** dan dapat dipulihkan atau dihapus permanen. Fitur impor dan ekspor tersedia seperti pada halaman master data lainnya.
