# Production & Commercial Defaults

Halaman **Production & Commercial Defaults** digunakan Super Admin untuk mengatur nilai bawaan produksi dan komersial, serta format tampilan angka, mata uang, dan tanggal.

## Produksi

Pengaturan produksi meliputi:

| Pengaturan | Keterangan |
| --- | --- |
| **Ambang batas kerf** | Ukuran ambang yang digunakan sistem untuk menghitung potongan sebagai kerf. |
| **Ambang batas offcut layak pakai** | Batas ukuran offcut. Offcut yang lebih kecil dari nilai ini dihitung sebagai scrap dan tidak dimasukkan ke stok. |
| **Penggunaan kembali offcut** | Menentukan apakah offcut layak pakai boleh digunakan kembali. |

## Komersial

Nilai bawaan komersial yang dapat diatur meliputi:

- Margin aluminium
- Margin kaca
- Diskon
- PPN
- Masa berlaku penawaran
- Waste aluminium
- Tingkat pembulatan

Super Admin juga dapat menentukan apakah harga master sudah termasuk PPN.

## Format Tampilan

Atur format angka, mata uang, dan tanggal yang digunakan pada layar dan dokumen.
