# Profil Aluminium

Halaman **Profil Aluminium** pada modul **Master Data** digunakan untuk mengelola profil aluminium yang digunakan dalam sistem.

## Menambahkan Profil Aluminium

1. Buka halaman **Profil Aluminium** dari modul **Master Data**.
2. Klik **Tambah Profil** di bagian atas halaman.
3. Isi **Kode Profil**, **Deskripsi** (misalnya *door window jamb*), **Deskripsi Lapangan** (misalnya *kusen tegak*), **Berat per Meter**, **Brand**, dan **Seri**.
4. Simpan profil.
5. Setelah profil tersimpan, lengkapi **Panjang Batang** dan **Finishing**.

## Mengimpor Profil Aluminium

1. Siapkan file berformat **.csv** atau **.xlsx** berisi data profil, termasuk **Kode Profil**, **Deskripsi**, **Deskripsi Lapangan**, **Berat per Meter**, **Brand**, dan **Seri**.
2. Klik **Impor** di bagian atas halaman.
3. Unggah file, lalu jalankan proses impor.
4. Periksa hasil impor pada tabel Profil Aluminium dan lengkapi **Panjang Batang** serta **Finishing** setelah profil tersimpan jika belum terisi.

## Menghapus, Memulihkan, atau Menghapus Permanen Profil

Alur penghapusan profil sama seperti pada [halaman Brand](/roles/super-admin/brand):

1. Pada kolom **Aksi** di tabel Profil Aluminium, klik ikon tempat sampah pada baris profil yang akan dihapus dan konfirmasikan jika diminta. Profil yang dihapus akan masuk ke kotak sampah.
2. Klik **Kotak Sampah** di bagian atas halaman.
3. Pilih profil yang akan dikelola, lalu pilih **Pulihkan** untuk mengembalikannya atau **Hapus Permanen** untuk menghapusnya secara permanen. Konfirmasikan tindakan jika diminta.

## Mengekspor Profil Aluminium

Klik **Export** di bagian atas halaman untuk mengunduh daftar profil aluminium dalam format Excel.

## Mengisi Harga Terendah Tanpa PPN

Kolom **Harga Terendah Tanpa PPN** pada tabel Profil Aluminium diisi melalui halaman **Price & Cost**, bukan dari halaman Profil Aluminium.
