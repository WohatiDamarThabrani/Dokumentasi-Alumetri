# Report

Modul **Report** pada Super Admin menyediakan ringkasan lintas project dan alat untuk membandingkan hitungan sistem dengan dokumen client.

## Halaman Report

- [Report](/roles/super-admin/report) — merangkum penawaran, performa project, produksi, kebutuhan material, scrap dan offcut, pengiriman, serta COGS internal.
- [Uji Rekonsiliasi](/roles/super-admin/uji-rekonsiliasi) — membandingkan hitungan sistem dengan hitungan client yang diunggah dalam format .xlsx.
