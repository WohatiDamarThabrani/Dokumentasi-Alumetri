# Seri Profil

Halaman **Seri Profil** pada modul **Master Data** digunakan Super Admin untuk mengelola seri profil berdasarkan brand.

## Menambahkan Seri Profil

1. Buka halaman **Seri Profil** dari modul **Master Data**.
2. Klik **Tambah Seri** di bagian atas halaman.
3. Pilih **Brand**, lalu masukkan **Kode Seri** dan **Nama Seri**.
4. Simpan seri profil.

## Mengimpor Seri Profil

1. Siapkan file **.csv** atau **.xlsx** dengan kolom **Brand**, **Kode**, dan **Nama Seri**.
2. Klik **Impor** di bagian atas halaman.
3. Unggah file, lalu jalankan proses impor.
4. Periksa hasil impor pada tabel Seri Profil.

## Menghapus, Memulihkan, atau Menghapus Permanen Seri Profil

Penghapusan seri profil menggunakan alur yang sama seperti pada [halaman Brand](/roles/super-admin/brand):

1. Pada kolom **Aksi** di tabel Seri Profil, klik ikon tempat sampah pada baris seri yang akan dihapus dan konfirmasikan jika diminta. Seri yang dihapus akan masuk ke kotak sampah.
2. Klik **Kotak Sampah** di bagian atas halaman.
3. Pilih seri yang akan dikelola, lalu pilih **Pulihkan** untuk mengembalikannya atau **Hapus Permanen** untuk menghapusnya secara permanen. Konfirmasikan tindakan jika diminta.
