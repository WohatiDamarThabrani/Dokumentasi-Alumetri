# Setting

Modul **Setting** digunakan Super Admin untuk mengelola informasi perusahaan dan elemen identitas yang ditampilkan pada dokumen.

## Halaman Setting

- [Company Information](/roles/super-admin/company-information) — mengelola identitas perusahaan, rekening, logo, dan penanda tangan yang digunakan pada dokumen.
- [User Management](/roles/super-admin/user-management) — membuat akun pengguna dengan nama, email, kata sandi awal, dan role.
- [Roles & Permissions](/roles/super-admin/roles-permissions) — mengatur izin aksi untuk setiap role.
- [Document Settings](/roles/super-admin/document-settings) — mengatur template cetak dan pola penomoran setiap dokumen.
- [Production & Commercial Defaults](/roles/super-admin/production-commercial-defaults) — mengatur nilai bawaan produksi, komersial, dan format tampilan.
- [Data Demo](/roles/super-admin/data-demo) — menyediakan fitur pengosongan data demo hanya di lingkungan development dan demo.
