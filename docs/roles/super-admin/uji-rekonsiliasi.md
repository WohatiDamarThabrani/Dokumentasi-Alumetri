# Uji Rekonsiliasi

Halaman **Uji Rekonsiliasi** digunakan untuk membandingkan hitungan sistem dengan angka pada dokumen dari client.

## Mengunggah Hitungan Client

1. Buka halaman **Uji Rekonsiliasi**.
2. Siapkan dokumen hitungan client dalam format **.xlsx**.
3. Unggah file tersebut melalui halaman Uji Rekonsiliasi.
4. Setelah file diproses, tinjau hasil perbandingan hitungan client dengan hitungan sistem.
