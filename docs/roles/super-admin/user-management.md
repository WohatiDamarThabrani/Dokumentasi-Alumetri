# User Management

Halaman **User Management** digunakan Super Admin untuk mengelola akun pengguna. Akun dibuat oleh Super Admin; pengguna tidak mendaftar sendiri.

## Menambahkan Pengguna

1. Buka halaman **User Management** dari modul **Setting**.
2. Pilih tindakan untuk menambahkan pengguna.
3. Isi **Nama**, **Email**, **Kata Sandi Awal**, dan **Role** pengguna.
4. Simpan akun pengguna.
