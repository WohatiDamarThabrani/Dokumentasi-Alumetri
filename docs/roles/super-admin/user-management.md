# User Management

Halaman **User Management** digunakan Super Admin untuk mengelola akun pengguna. Akun dibuat oleh Super Admin; pengguna tidak mendaftar sendiri.

## Cara Menambahkan Pengguna

1. Buka menu User Management.
   <img src="/images/super-admin/user-management/um1.png" alt="Langkah 1: Pilih menu Daftar Surat Jalan" style="display: block; max-width: 100%; height: auto;">

2. Klik tombol <img src="/images/super-admin/user-management/um2.png" alt="Buat Surat Jalan" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;">, lalu akan muncul form berikut
    <img src="/images/super-admin/user-management/um3.png" alt="Formulir pembuatan surat jalan" style="display: block; max-width: 100%; height: auto;">

3. Masukkan nama, email, kata sandi awal. Lalu pilih peran pengguna

4. Klik tombol <img src="/images/super-admin/user-management/um4.png" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> 

## Cara Menonaktifkan Pengguna

1. Buka menu User Management.
   <img src="/images/super-admin/user-management/um1.png" alt="Langkah 1: Pilih menu Daftar Surat Jalan" style="display: block; max-width: 100%; height: auto;">

2. Klik baris pengguna yang ingin dinonaktifkan. Lalu akan muncul form seperti berikut
    <img src="/images/super-admin/user-management/um5.png" alt="Langkah 1: Pilih menu Daftar Surat Jalan" style="display: block; max-width: 100%; height: auto;">

3. Klik tombol <img src="/images/super-admin/user-management/um6.png" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> yang berada di bagian bawah form. Gulir form ke bawah untuk menemukan tombolnya

Pengguna berhasil dinonaktifkan
